# 🌍 java-explore-with-me

Платформа для поиска событий и компании. Пользователи могут создавать мероприятия (концерты, встречи, походы), указывать дату, место и описание, а также подавать заявки на участие. Есть возможность подписываться на других пользователей, чтобы следить за их новыми событиями. Проект состоит из двух микросервисов: основной отвечает за события и пользователей, а сервис статистики собирает данные о просмотрах. Оба сервиса работают с PostgreSQL и объединены через Docker Compose.

---

## ✨ Функциональность

- Создание и публикация событий
- Поиск событий по категориям, датам, локации
- Подача заявок на участие в событиях
- Подтверждение или отклонение заявок организатором
- Подписка на других пользователей
- Сбор и отображение статистики просмотров событий
